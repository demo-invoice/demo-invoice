## Print stylesheet

A browser print fallback stylesheet is provided at `src/styles/print.css`.
It hides UI chrome, removes decorative shadows, and prevents table rows from
splitting across page boundaries when a user prints an invoice via **Ctrl+P**.

See [TESTING.md](./TESTING.md) for manual verification steps and selector
confirmation notes.
