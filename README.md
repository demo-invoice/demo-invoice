# demo-invoice

Initialized by your AI team so we have a base branch to build on.

## Features

- **Send invoice by email**: Users can now send invoices directly from the app by selecting an invoice and providing an email address.

## Usage

1. Open the app and navigate to the invoice section.
2. Select an invoice by entering its ID.
3. Enter the recipient's email address.
4. Click the 'Send Invoice' button to send the invoice via email.

## Edge Cases Handled

- User selects an invoice but no email address is provided
- Email service is unavailable or returns an error
- Invoice data is incomplete or invalid
- User cancels the email sending process
